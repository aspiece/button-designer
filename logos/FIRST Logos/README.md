# FIRST Logos

This directory is reserved for official artwork downloaded from the [FIRST brand and logo guidelines](https://www.firstinspires.org/brand/logos-guidelines?hsLang=en).

Use unmodified files supplied by FIRST. Do not change colors, proportions, design elements, or required clear space. Some stand-alone FIRST components require the full FIRST logo to appear elsewhere.

The `scripts/refresh_logos.py` workflow imports official PNG assets here. Team-created logos belong in the parent `logos/` folder.
